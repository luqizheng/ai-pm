### 3.1 Migration 0035（GAP-37-C）

`CREATE TRIGGER trg_projc_version_delete BEFORE DELETE ON projc.cognition_version FOR EACH ROW EXECUTE FUNCTION projc.forbid_row_update();`（0001:7050 pc 真源逐字同款；零新函数）。

### 3.2 Migration 0036（GAP-38-A）

- **PRIMARY KEY ×18**（pc 同款：16×`PRIMARY KEY (id)`；object_type/relationship_type×`PRIMARY KEY (type_key)`）；
- **业务身份 UNIQUE ×4**（pc 同款约束名逐字镜像）：
  - cognition_version_tenant_id_project_id_version_no_key
  - document_tenant_id_project_id_doc_key_key
