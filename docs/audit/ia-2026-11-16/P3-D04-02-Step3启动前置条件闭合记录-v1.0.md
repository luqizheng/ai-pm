### 1.2 实施方案（草案，**待批准后执行**）

```sql
-- 0028_projc_object_key_unique.sql（编号顺延；纯增量，无数据迁移/回填/兼容分支——AGENTS.md 规则 1）
ALTER TABLE projc.cognition_object
    ADD CONSTRAINT cognition_object_tenant_id_project_id_object_key_key
    UNIQUE (tenant_id, project_id, object_key);
```

- 与 PC **逐字段同款**（列、顺序、约束名、NULLS DISTINCT 语义）——`projc/object.rs:60-90` 先查后插路径获得 DB 兜底，匿名草稿分支（object_key=NULL）不受影响；
- 0026「0025 缺陷修正」同款登记模式（纯增量正确性修正），不触碰冻结契约。
