## 二、触发器与服务层职责边界

```
服务层（唯一推进面）                DB（约束与拒绝）
─────────────────────              ─────────────────────
create/submit/decide/withdraw/     forbid_approval_mutation（锚列不可变）
publish/expire(T-10) 状态推进      enforce_object_lifecycle（终态保护）
+ FOR UPDATE+CAS+行数断言          enforce_write_op_state（账本终态不可回改）
                                   forbid_version_mutation（版本单向）
                                   （GAP-06 未来补：proposal 转换守卫——纯拒绝式）
```

- 现有触发器**全部为拒绝式**（本轮抽读 enforce_write_op_state 函数体：仅 RAISE EXCEPTION，零 DML）——无状态推进逻辑混入；
- **KB/PC=正式认知内容权威；PostgreSQL=ID/状态/版本引用/审批/状态机/审计/事件等结构化治理事实**——Step 3 全部设计（账本扩展/expire 列/指纹列）只增治理事实承载，未把认知正文权威转移给数据库。✓
