## 〇、前置：§1.2 全生命周期域修正登记（文档精度问题，非 GAP）

审阅方问题：**是否存在合法路径使账本已 failed 而提案仍 approved**（如失败记录保留后重试未提交时他连接读到 `(approved, failed)`）？

**取证结论（CODE FACT）**：
1. 账本行以 failed 提交的唯一服务层路径=CAS 失配——**同事务**将提案一并置 failed（publish.rs:305-325）→ 自然路径下 `(failed, failed)` 恒成对，`(approved, Some("failed"))` **不共存**；
2. 发布入口守卫 `required_status="approved"`（:225-228）+0034 无 `failed→approved` 出边（failed 提案须 re-propose=新 id 新键）→ 不存在"failed 账本行+approved 提案"的重试入口；
3. **但**：直写注入（既有测试惯用）与 :197-207 注释明示的"pending/failed 行重放"预留路径下，该组合**可被构造**——且属**两行各自独立合法提交的历史组合**（状态组合域问题），**不是快照撕裂**（快照一致性命题只约束"同一发布提交的两行"，不受影响）；
4. **R-1 分类免疫**：契约 3/4（仅 `applied∧completed` 归 replay；不满足时不得仅凭账本推断成功）使 `(approved, failed)` 落入 failed 分类=保守正确。

**处置**：V1.1 §1.2 的 `w=Some("failed") ⇒ p='failed'` 行修正为「**服务层自然路径下**成立；注入/预留重试路径下 `(approved, failed)` 为可构造的合法历史组合——属状态组合域，非快照撕裂，分类契约免疫」。本登记随方案归档，不改测试（测试白名单针对无历史账本的首次发布场景，仍精确正确）。

### D1 `crates/pm-application/src/analysis_report.rs` — pc 段（:596-605）

```rust
// BEFORE（现状）
match crate::pc::publish_version(pool, project_id, actor,
        crate::pc::PublishVersionInput { proposal_id }).await {
    Ok(_) => applied_proposals += 1,
    Err(_) => publish_failed_proposals += 1,
}

// AFTER（预期）
match crate::pc::publish_version(pool, project_id, actor,
        crate::pc::PublishVersionInput { proposal_id }).await {
    Ok(_) => applied_proposals += 1,
    Err(_) => {
        // R-1 计数语义（Q10-R1-FIX-01）：单条 JOIN 单语句快照读取两事实
        // （契约 1/2；禁止两条 SELECT）；仅 applied∧completed 归 replay
        // （契约 3）；其余一律 failed——不凭账本单独推断成功（契约 4）。
        let row: Option<(String, Option<String>)> = sqlx::query_as(
            "SELECT p.status, wo.status FROM pc.proposal p \
              LEFT JOIN pc.write_operation wo \
                ON wo.tenant_id = p.tenant_id AND wo.project_id = p.project_id \
               AND wo.operation_id = 'pc-decision:' || p.id::text \
             WHERE p.id = $1",
        )
        .bind(proposal_id)
        .fetch_optional(pool)   // 独立连接；不进外层事务（锁序零参与）
        .await
        .unwrap_or(None);       // 重读自身异常→保守 failed（不引入新错误路径）
        if let Some((p, w)) = row {
            if p == "applied" && w.as_deref() == Some("completed") {
                replayed_proposals += 1;
                continue;
            }
        }
        publish_failed_proposals += 1;
    }
}
```
