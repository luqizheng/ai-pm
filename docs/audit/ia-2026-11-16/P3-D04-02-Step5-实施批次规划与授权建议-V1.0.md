## 七、第一批实施建议（推荐=批 1：GAP-04+GAP-37-A/B）

**为什么适合作为第一批**：
1. **零行为变化**：纯增量 DB 保护；当前代码全部写路径为 INSERT（§五.1/§五.2 证据），不触碰 UPDATE/DELETE；行锁推号保证服务层不产生重复——现网功能与数据零影响；
2. **证据最全**：GAP-37 函数体已核实可行（§五.1）；GAP-04 活库预检 0 重复已过（§五.2，同 A-1 前置检查模式）；
3. **回滚最简**：DROP CONSTRAINT/TRIGGER 即完全回退，单语句迁移无数据变更；
4. **战略位最优**：在批 3/4 扩展写路径之前先补防御纵深（总账 GAP-37 行明示此逻辑：GAP-01/27/36 实施将扩写路径面）；
