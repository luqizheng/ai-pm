### 验证 3：object_key=NULL 多行插入仍然合法（NULLS DISTINCT 保持）✓

事务内验证（ROLLBACK 收尾，零残留）：
```
BEGIN;
INSERT ... object_key=NULL, display_name='v-null-1'  → INSERT 0 1
INSERT ... object_key=NULL, display_name='v-null-2'  → INSERT 0 1
SELECT count(*) WHERE object_key IS NULL → 2
ROLLBACK;
SELECT count(*) WHERE object_key IS NULL → 0   -- 回滚零残留
```
两条 NULL key 插入均成功——未误改为 NULLS NOT DISTINCT（任务书 §四 红线）。
