## 一、意图与背景

设计系统 V1.0 与总控台 V1.1 两稿供稿完成（2026-10-31），分析稿给出实施前裁决建议。用户 /goal 指令：根据文档，自动采用 superpowers 写 spec 和 plan，然后自动执行；睡前追加三裁决：**总控台竖切、默认深色、只本地 commit**。

设计判断（V1.1 供稿原文）：总控台不是用来展示所有项目数据的，而是帮助用户快速判断项目状态、决定是否需要介入，并指挥 AI 团队继续工作。页面优先级：**待我处理 → AI 负责人简报 → 执行态势 → 目标进展 → 项目动态**。

P0 竖切目标（分析稿 §7.5）：**shell + 总控台单页竖切**，验证三栏框架与 AI 指令栏上下文引用，再铺开其余页面。全部数据走前端 fixtures（零 BFF/后端改动），与 V1.1 原型「所有数据均为设计演示数据」一致。

## 二、P0 范围

1. **前端迁仓落地**（既定裁决的执行）：ai-pm-web/frontend → ai-pm/frontend（前后端同仓）。ai-pm-web 本仓只读不动（含其未提交变更）；BFF 不随迁（随迁与否未裁决，且 P0 零 BFF 改动，前端代理目标不变）。
2. **设计 token 体系**：tokens.css 全集（表面/文本/AI 强调/语义色/focus ring/密度/布局尺寸）+ 深浅双主题 + 防闪烁预挂载 + useTheme 持久化 + PRISM token 桥接与门禁白名单过渡。
3. **Workspace Shell**：TopBar 52px（面包屑+主题切换）· 左导航 232px↔60px 折叠（V1.1 双分组 IA）· 主工作区自适应 · 右上下文栏 320px 可折叠 · AI 指令栏 72–120px 属 main 列底部固定。
4. **总控台页 V1.1**（/workspace/:projectId/console）：项目状态徽标 + AI 负责人简报 + 指标卡 ×3（执行态势）+ 需要你处理（决策/验收/阻塞三类，选中态联动右栏）+ 目标进展（简版）+ 项目动态（简版）。
5. **右侧上下文栏**：当前待办事项（跟随选中）、AI 建议、占位区 ×2（批量原型验证/补充证据）。
6. **AI 指令栏**：上下文 chip（AI 研发负责人 · 当前页面上下文）、/ 引用 · @ Agent 占位、发送→阶段显示+可取消→mock 回复气泡、Esc 关闭。
7. **入口与键盘**：dashboard 加「AI 工作空间（预览）」入口；Ctrl+/ 聚焦指令栏；可见 focus ring。

## 五、总控台页规格（V1.1 供稿照录要素）

自上而下（Shell 级指令栏常驻底部，不属页面）：

1. **页头**：标题「项目总控」+ 绿徽标「项目运行中」+ 副题（项目名 / Iteration 2.0 / 演示数据）
2. **AI 负责人简报**：署名「元构 · 今天」；正文；💡 建议行（「优先确认地形渲染方案，再推进相关实现」）
3. **指标卡 ×3**：12 迭代任务（5 项执行中）/ 03 需要介入（1 项最优先）/ 04 活跃 Agent（1 等待审批）
4. **需要你处理**（右上角「3 项」）：地形渲染架构评审（决策·橙，选中态紫描边）/ 高保数据模块验收（验收·蓝）/ 森林生成性能页（阻塞·红）；点击卡片→选中态+右栏「当前待办事项」「AI 建议」联动
5. **目标进展**（简版 GoalCard 占位）与 **项目动态**（简版：重要变更/执行失败/近期决策 3–4 条）
6. **右侧上下文栏**「上下文」：当前待办事项 / AI 建议（先验证 Shader 原型性能，再做正式架构选择）/ 占位区「批量原型验证」「补充证据」

## 六、工程约束

- 新增依赖**零**（zod 等 P1 协议任务才需要）；不换路由/状态库/UI 库。
- 所有新文件 **LF 行尾**；提交前过 prettier（CRLF 曾打挂契约测试）；界面文案全走 vue-i18n（zh-CN/en 同步）。
- **并行会话对策**：ai-pm 仓有并行会话史——动手前 git status 体检、每任务立即 commit、写操作一律绝对路径。
- 测试：vitest `pnpm test:unit`，组件测试 `*.test.ts` 同目录模式（以现仓实际设施为准）。
- 生命周期硬规则（沿用旧 P0 计划约束）：可执行动作不得本地点击即判成功；P0 无真后端，指令栏发送由 mock 回执驱动，但 loading/取消/失败状态机必须完整。

## 七、验收判据

1. `/workspace/:projectId/console` 直达渲染 V1.1 全部区块+右栏+指令栏（演示数据）；未知 projectId 降级页不白屏。
2. 主题深↔浅切换全组件不破相；刷新后主题保持、无闪烁（预挂载脚本）。
3. 左栏 232↔60 折叠、右栏可折叠；<1280px 隐右栏、<1024px 左栏折叠至图标栏（B-2 沿用）。
4. 待处理卡点击→选中态+右栏联动；指令栏 chip 显示当前上下文。
5. 指令栏：发送→阶段+可取消→mock 回复；Esc 关闭；Ctrl+/ 聚焦。
6. 语义色与正文对比度达 WCAG AA（脚本核验记录留档）。
7. 门禁：`pnpm test:unit` 全绿、`pnpm build` 通过、prettier 通过、CRLF=0。
8. 设计系统验收清单（§七）P0 适用子集逐条核对，结果记录进收尾报告。
