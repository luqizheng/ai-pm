## 3. 缺陷记录

### B03-01（P1）
- 需求意图消息被续接到 **REVIEW_REQUIRED** 会话后成为死信：编排器只扫 IN_PROGRESS/NEEDS_USER_INPUT，REVIEW_REQUIRED 会话内的新用户消息无回复、无处理、无任何提示；且 UI 无「完成会话」按钮（transitionDiscoverySession 前端零调用），会话无法人工完结 → 需求话题消息**永久黑洞**
- 复现：会话到 REVIEW_REQUIRED 后在 chat 发任何含需求关键词消息
- 影响：核心对话功能被吞；用户无感知
- 严重程度：**P1**
- 本验收经产品 API 手动完结会话解锁（NEEDS_USER_INPUT→COMPLETED）

### B03-02（P2）
- chat AI 的上下文只含项目画像，不含需求库/发现/知识内容；「知识被后续对话使用」不成立，用户需手动粘贴正文
- 影响：AI-PM 无法自主引用已确认需求，跨会话知识复用断裂

### B03-03（P2）
- 访谈收敛不可控：全部问题已答、发现已裁决后，编排器仍持续产出新发现（3 次「请进入评审」后仍 +2 findings），无人工强制进评审的 UI/入口
- 影响：访谈无法干净收尾，依赖 API 手工完结

### B03-04（P3）
- /project/discovery 直接访问时 shell 偶发回落展示总控台内容（路由/壳状态不稳定，1 次）

### B03-05（P3）
- 会话 2 首轮 3 问与此前 chat 已答复内容重复（编排器未消费跨会话历史）
