## 冻结的设计原则

1. 基线允许持续演进。
2. 基线版本不可覆盖。
3. 当前有效基线始终唯一。
4. 正式确认必须由人类完成。
5. AI 负责分析、提案、修订和证据整理。
6. 基线变更必须保留历史及影响追溯。
