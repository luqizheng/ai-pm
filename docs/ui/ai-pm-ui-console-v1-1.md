这次继续深入 AI 总控台的高保真桌面端设计。把它当作一个真正要交付开发的产品页面来设计，而不是简单的 Dashboard 卡片展示。

**重要设计判断：总控台不是用来展示所有项目数据的，而是帮助用户快速判断项目状态、决定是否需要介入，并指挥 AI 团队继续工作。**

页面优先级：**待我处理 → AI 负责人简报 → 执行态势 → 目标进展 → 项目动态**。

## 一、可交互的 AI 总控台原型

下面的原型可以切换深浅主题、查看待处理事项、选择 Agent、展开右侧上下文、切换总控视角，并模拟决策处理。所有数据均为设计演示数据。

图面记录（文字照录；图面小字按视觉辨认，个别字如与原图有出入以原图为准）：

- **顶部栏**：面包屑「Atlas R&D › 世界地图编辑器」；右侧主题、视图、通知、账户（PM）图标
