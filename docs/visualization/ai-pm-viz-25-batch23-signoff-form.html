R-09 derived_trace Owner：architecture-owner
来源
VizSpec 合成（不对应任何业务关系表）
端点
由实际推导路径中的对象决定
标记
synthetic: true · business_fact: false
级别
L2

语义：Visualization 根据已存在的直接关系推导出的间接追踪关系（如 Task → Requirement ← Design）；不代表两端存在直接业务绑定。

专家硬约束：不得成为任意用户或 AI 可自由写入的关系——必须有明确来源、推导规则与安全约束。必须携带 direct=false + via + semantic_confidence；图中虚线并标「经 X 推导」；影响分析归 Indirect；路径上每条直接关系都要过 Registry 校验与权限过滤；中间路径存在无权对象时不得通过合成边暴露其存在；不得写回业务表或用于审批与状态变更。
