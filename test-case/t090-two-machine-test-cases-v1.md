## 6. 已知风险（执行时重点观察）

1. **.43 防火墙**：当前从 .4 侧全端口被过滤——若用远程操作需先放开；本机操作则无影响。
2. **仓库可达性**：demo 仓库的 git URL 必须是 .43 能访问的（TC-303 例外地需要不可达的）。
3. **token-service 重启换密钥**：中途重启服务器栈会使旧 JWT 失效，TC-203-① 可借力但注意别误伤其他用例。
4. **key 绑定**：key 必须绑定真人 principal 且在该租户内；`platform_admin` 会被 `ct=true` 拒（403 IAM_PERM_3004）。
5. **执行端差异**：Z-Code 与 Codex 的技能目录/配置位置不同——skill 按 `/install/{tool}` 指引落盘，若指引与实际不符属缺陷（记下工具名与现象）。
